# Descripción del Proyecto
Software que automatiza el proceso de titulación y certificación del Instituto, integrando la información académica con la plataforma provincial TGD del Ministerio de Educación. Reduce tiempos de trámite, elimina duplicación de datos y garantiza trazabilidad.

- `docs/datos/` → Diccionario de datos

Durante la elaboración de este proyecto se utilizaron asistentes de IA con los siguientes propósitos, revisión y corrección integral:
